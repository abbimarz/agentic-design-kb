# Skills Catalog — Visual Design

Skills focused on UI aesthetics and art direction, mostly landing-page /
marketing-surface oriented.

### [Front End Design (Anthropic)](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md)
Walks through a UX design-thinking process before generating anything:
purpose, tone, constraints, differentiation. Picks fonts and aesthetic
direction itself. Explicitly told to avoid "AI slop." Best fit: landing page
design.

### [Impeccable](https://impeccable.style/)
Similar territory to Front End Design, but adds 20+ slash commands (`harden`,
`quieter`, `optimize`, etc.) for fast art-direction adjustments. Includes a
`/critique` command that runs heuristic, accessibility, and other
evaluations against the output. Best fit: landing page design.

### [Implement Design (Figma)](https://mcpservers.org/agent-skills/figma/implement-design)
Translates a Figma link into production-ready code, matching fidelity as
closely as possible. Reads and reuses existing components rather than
rebuilding from scratch. **Requires the Figma MCP to be connected** — see
[../foundations/05-connecting-tools.md](../foundations/05-connecting-tools.md).

### [Theme Factory](https://mcpservers.org/agent-skills/anthropic/theme-factory)
Quickly applies a chosen style/vibe to simple deliverables — presentations
and similar lightweight outputs.

### [Canvas Design](https://mcpservers.org/agent-skills/anthropic/canvas-design)
Defines a design philosophy up front, then generates visual directions
(posters, images, etc.) from it.

### [Emil Kowalski Skill](https://emilkowal.ski/)
Packages one senior designer's specific knowledge into a skill — animation,
performance considerations, interaction fundamentals and patterns. Best fit:
motion/animation work.

# Skills Catalog

A directory of Claude Skills worth knowing about, organized by discipline —
not by which project you used them on. This grows independently of
[applications/](../applications/README.md): a skill listed here might get
used across several different application domains.

## Categories

- [visual-design.md](visual-design.md) — landing pages, UI aesthetics, art
  direction
- [product-design.md](product-design.md) — interaction/interface design for
  apps, dashboards, SaaS
- [design-systems.md](design-systems.md) — tokens, component libraries,
  brand governance
- [research-and-analysis.md](research-and-analysis.md) — discovery,
  competitive research, content/data mining
- [marketing.md](marketing.md) — social media strategy, writing, and
  performance analysis

## Adding a new skill entry

1. Find (or create) the category file that fits — add a new category file
   here only if a skill genuinely doesn't fit any existing one (e.g. a future
   "marketing.md" or "3d-modeling.md" once you're actually using skills in
   those disciplines).
2. Under the right category, add:
   ```md
   ### Skill name
   What it does, one or two lines. What it's best for. Any setup dependency
   (e.g. "requires Figma MCP").
   ```
3. Link out to [applications/](../applications/README.md) if there's a
   concrete example of the skill in use — keep the "what it is" here and the
   "how I used it" there.

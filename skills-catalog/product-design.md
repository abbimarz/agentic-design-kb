# Skills Catalog — Product Design

Skills focused on interaction and interface design for applications rather
than marketing surfaces.

### [Interaction Design](https://www.ui-skills.com/skills/interaction-design/)
Designs and implements microinteractions, motion design, transitions, and
user feedback patterns — hover/active/other subtle states covered as a set.

### [Interface Design](https://www.ui-skills.com/skills/interface-design/)
Specialized for dashboards, admin panels, and SaaS apps — focused on craft
and consistency. Saves design decisions to a `system.md` file so the project
stays consistent across sessions rather than re-deciding conventions every
chat.

### [Web Design Guidelines](https://www.ui-skills.com/skills/web-design-guidelines/)
Reviews UI code for compliance with web interface best practices — audits
design, accessibility, and UX against an established guideline set (e.g.
Vercel's interface guidelines).

### [Behavioral Product Design](https://github.com/RefoundAI/lenny-skills/tree/main/skills/behavioral-product-design)
Applies behavioral-science framing (from Lenny's skill pack) to product
design decisions — not yet tried, filed here for when it's relevant.
